{%- comment -%} Lists every slash page, generated at build time — no manual upkeep. A page counts as a slash page when its URL is a single segment ("/why/") or it sets `slash: true`. Opt a page out with `slash: false`. Each entry shows `blurb:` (falls back to `description:`). Usage: {% include slash-pages.html %} → name + blurb {% include slash-pages.html compact=true %} → names only {%- endcomment -%} {%- assign all_pages = site.pages | sort: "url" -%}
